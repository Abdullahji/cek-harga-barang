PENGATURAN DATABASE & SINKRONISASI

Menghubungkan Database Google Sheets Anda

  1. Buat spreadsheet baru di Google Drive Anda.
  2. Buka menu: Extensions > Apps Script.
  3. Buka tab code.gs dari file project ini, lalu salin seluruh kodenya.
  4. Hapus semua kode bawaan di editor Apps Script Anda, dan Paste (Tempel) kode tersebut.
  5. Klik opsi simpan (ikon disket).
  6. Klik Deploy > New deployment.
  7. Pilih jenis (Type) Web app.
  8. Atur "Execute as" ke Me (email Anda) dan "Who has access" ke Anyone.
  9. Lakukan otoritas akses jika diminta, klik Deploy, lalu salin URL Web App yang dihasilkan.
  10. Paste URL tersebut pada input di bawah ini, klik Simpan Koneksi atau Uji Koneksi.
