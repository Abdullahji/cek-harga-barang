PENGATURAN DATABASE & SINKRONISASI

Menghubungkan Database Google Sheets Anda

  1. Buat spreadsheet baru di Google Drive Anda.
  2. Buka menu: Extensions > Apps Script.
  3. Salin kode Apps Script (code.gs) terbaru dengan klik tombol di bawah ini:
  4. Hapus semua kode bawaan di editor Apps Script Anda, lalu Paste (Tempel) kode yang sudah disalin tersebut.
  5. Klik opsi simpan (ikon disket).
  6. Klik Deploy > New deployment.
  7. Pilih jenis (Type) Web app.
  8. Atur "Execute as" ke Me (email Anda) dan "Who has access" ke Anyone.
  9. Lakukan otoritas akses jika diminta, klik Deploy, lalu salin URL Web App yang dihasilkan.
  10. Paste URL tersebut pada input di bawah ini, klik Simpan Koneksi atau Uji Koneksi.
CARA MENGATASI ERROR "DriveApp" / AKSES DITOLAK:

Jika Anda mendapat pesan error "Exception: 存取遭拒：DriveApp / Access Denied: DriveApp" saat mengunggah gambar barang, hal itu disebabkan Google memblokir akses ke Drive Anda. Silakan ikuti langkah ini untuk memperbaikinya:

  • Buka kembali lembar Apps Script Anda di Google Sheets.
  • Pastikan pengaturan "Execute as" saat Deploy diatur ke "Me" (Email Anda), jangan pilih 'User accessing the web app'.
  • Tingkatkan versi deployment dengan cara: Klik Deploy -> New deployment -> Klik Deploy.
  • Google akan memunculkan popup "Authorization Required". Klik tombol "Authorize Access".
  • Pilih akun Google Anda -> Klik tombol "Advanced" (Lanjutan) di kiri bawah -> Klik "Go to Toko Wina (unsafe)" -> Klik "Allow" (Izinkan).
  • Salin URL Web App yang baru dan simpan kembali di aplikasi.
* Pastikan URL diakhiri dengan /exec dan Anda mendeploy ulang (New version) setelah mengubah code.gs.
